\section{Evaluation}
\label{sec:evaluation}

No evaluation is reported, because there is no implementation to evaluate.

This follows a deliberate scope decision rather than an omission. Building
Ingestion, Normalization and Synthesis to the standard
Sections~\ref{sec:carta} and~\ref{sec:algorithms} specify is substantial work, and
a partial implementation produced quickly in order to report numbers would be
worse than none: it would attach measurements to something that does not implement
the specification the measurements would be read as validating. An evaluation
section will be written when an evaluation has actually been run, populated from
that run's output. Until then this paper reports no benchmark, no accuracy figure,
and no performance measurement, and the reader should treat every property in
Section~\ref{sec:carta:invariants} as a requirement placed on implementations
rather than an observed result.
